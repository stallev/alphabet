# DESIGN.md — визуальная система Circle («Утренний свет»)

Источник правды для токенов и запретов. Прототип: [`prototype/index.html`](prototype/index.html), вкладка **B · Утренний свет (v1)**. Аудит и контекст: [`design_audit_and_concepts.md`](design_audit_and_concepts.md). Токены в коде: [`design_tokens_contract.md`](../implementation/contracts/design_tokens_contract.md).

Статус: **утверждён** (выбор заказчика, 2026-11-03). Направления «Табло», «Сетка», «Станок» и вкладки A, C, D–F прототипа сняты и оставлены только для сравнения.

## Условия, из которых всё вытекает

- Играют командой у общего экрана (проектор в освещённой комнате, ТВ, ноутбук) и по одному на телефоне. Читаемость с 3–5 м, крупные цели.
- Только светлая палитра, без переключателя тем.
- Нейтральная духовная стилистика: никакой сакральной символики, «библейских» гарнитур, витража.
- 5–6 игр в каталоге: фильтров нет.
- Языки: ru, en (активны), uk, de, ro (выключены). Шрифт — с кириллицей.

## Характер

Спокойный, воздушный, светлый: бледно-голубой фон, крупные непрозрачные белые карточки с мягким скруглением, один тёплый акцент («солнце») и один холодный («бирюза»). Характер задают типографика, пропорции и цвет игр, а не декор.

## Запреты (проверяются при ревью)

| Что | Почему |
|-----|--------|
| Радиус вне токенов `radius-ctl` (10) / `radius-ctl-sm` (8) / `radius-card` (18) / `radius-full` | единая форма; произвольные `rounded-[..]` запрещены |
| Тень вне токенов `shadow-card` / `shadow-press` | одна тень на роль; `shadow-2xl`, свечения `0 0 Npx` запрещены |
| Размытые пятна и «свечения» (`blur-*` на декоративных блоках, в том числе пятно в hero) | на проекторе вымываются; это шаблон |
| `backdrop-filter` где-либо, кроме липкой шапки портала | светлое полупрозрачное на светлом не стекаем; карточки и диалоги непрозрачные |
| Градиенты (фоны, текст, кнопки) | шаблон |
| Индиго/фиолетовый как основной цвет, дефолтные палитры Tailwind | основной цвет — бирюза; палитра только через токены |
| Эмодзи в интерфейсе | иконки — одна библиотека (`lucide-react`), цвет по токену |
| `uppercase`, `italic`, `font-black` как приём оформления, `tracking-widest` | иерархия — размером и весом (500–800) |
| `transition: all`, `hover:scale`, пульсация, случайные повороты | анимация только там, где несёт смысл (флип карточки, таймер, смена хода) |
| Чистые `#000` / `#fff` в тексте | чернила `ink` с подмесом; белый — только фон карточки |
| Цвет как единственный носитель смысла | состояние = форма/иконка + текст + цвет |
| Лозунги и описание дизайна в тексте интерфейса («спокойный светлый интерфейс…») | тексты конкретные: факт или глагол |
| Текст меньше 14 px (`text-[8–11px]`) | читаемость с проектора |

## Токены (семантические)

Значения — в [`design_tokens_contract.md §2`](../implementation/contracts/design_tokens_contract.md); здесь роли и опорные значения.

| Токен | Опорное значение | Роль |
|-------|------------------|------|
| `bg` | `#EAF2F4` | фон страницы |
| `surface` | `#FFFFFF` | карточки, диалоги, поле |
| `surface-muted` | `#EEF4F5` | вторичные области, подложка сегмент-контролов |
| `border` | `#C9D8DC` | тонкие разделители |
| `fg` | `#12303A` | основной текст |
| `fg-muted` | `#4A6068` | вторичный текст (≥ 4.5:1 на `bg`) |
| `primary` / `primary-fg` | `#0F766E` / `#FFFFFF` | выбранное состояние, ссылки, основная кнопка вторичных экранов |
| `accent` / `accent-fg` | `#F5A524` / `#12303A` | главное действие и текущий ход |
| `success`, `danger` | подбираются в R03-T1 | верно/неверно, только вместе с иконкой и текстом |
| `focus` | `primary` | кольцо фокуса 3 px с отступом 2 px |
| `team-1…6` | см. контракт | команды: цвет + номер/метка |
| `game-1…5` (+ `-fg`) | `#0F766E`, `#1D5FBF`, `#F5A524`, `#B4452A`, `#5B4BB7` | цвет плитки игры в каталоге |

Акцент `accent` — не больше двух применений на экран: главное действие и текущий ход. Красный `danger` не используется как цвет сложности (никакого «светофора»): уровни различаются числом очков, формой и подписью.

## Типографика

- Шрифт: **Manrope** 500–800, subsets `latin`, `cyrillic`; один семейство (`next/font`).
- База 18 px (проектор), `line-height` 1.5; заголовки 1.05. Размеры в `rem`.
- Трекинг по размеру: крупное `-0.02…-0.03em`, мелкое `0…+0.02em`. Минимум 14 px.
- Табличные цифры (`tabular-nums`) для очков и таймера.

## Форма, отступы, материалы

- Радиусы: контролы 10 px, мелкие сегменты/badge 8 px (`radius-ctl-sm`), карточки 18 px, круглые элементы (счёт, таймер) — `radius-full`.
- Тени: `shadow-card` (двухслойная, мягкая, цвет — из `fg`) для карточек и поля; `shadow-press` (inset) для нажатого/вложенного элемента. Больше ничего.
- Высоты контролов: 44 (обычный) и 56 (главное действие, проектор). Рядом стоящие — одной высоты. Минимальная цель касания 44 px (WCAG).
- Сетка 8 px. Отступы секций 48/96, контейнер `max-w-6xl`, боковые поля 20 px.
- Плитка игры: цвет `game-N` с глифом (буква/символ игры), контраст глифа ≥ 7:1.
- Игровое поле: 13 колонок × 4 ряда (52 карточки), на узком экране 7 и 4 колонки (R04).
- Открытая буква карточки — на `accent` с текстом `accent-fg`; контраст ≥ 7:1.

## Движение

- Отклик на нажатие мгновенный (`:active`, масштаб до 0.98, 100 мс).
- Флип карточки — spring без отскока, только `transform` (R04).
- Таймер — линейный, без пульса; при < 5 с меняются цвет и форма (иконка/штриховка).
- `prefers-reduced-motion`: флип заменяется кросс-фейдом, анимации диалогов отключаются.

## Мини-чеклист ревью

1. Нет градиентов, эмодзи, размытых пятен, теней и радиусов вне токенов.
2. Акцент ≤ 2 раза на экран.
3. Все пары текст/фон ≥ 4.5:1, крупное и буква на карточке ≥ 7:1.
4. Контролы одного ряда одной высоты; цель касания ≥ 44 px.
5. Нет лозунгов; кнопка называет действие.
6. Нет `uppercase`, `font-black`, текста мельче 14 px.
