# Аудит дизайна EdenGames и концепции редизайна

Дата: 2026-10-24. Источники: код репозитория (ветка R03) и живой деплой `alphabet-bible-quiz.vercel.app` (десктоп 1568 px; страницы `/`, `/alphabet`, `/alphabet#rules`, игровое поле после «Start game», `/admin/login`). Мобильный viewport через расширение не удалось эмулировать — мобильные выводы сделаны по коду и помечены «(код)».

## 1. Контекст, от которого надо отталкиваться

- Это **каталог** христианских игр для подростков и молодёжи, а не одна игра. Сейчас каталог (`/`) — заглушка из одной карточки, а весь «бренд» живёт внутри игры «Алфавит».
- Играют **командой у общего экрана** (проектор, ТВ, ноутбук на круге) и по одному на телефоне. Значит: читаемость с 3–5 метров, крупные цели, быстрый вход в игру, пауза/возврат без потери прогресса.
- Аудитория 13–25 лет: чувствует «как у взрослых по приколу» и «церковный плакат» одинаково фальшиво. Нужна собственная интонация, а не стоковая «Bible app».

### Принятые решения (заказчик, 2026-10-24)

| Вопрос | Решение | Следствие для дизайна |
|--------|---------|-----------------------|
| Светлая/тёмная тема | **Только светлая палитра**, рассчитанная на освещённые помещения и проектор. Переключателя тем нет. | Тёмный режим не проектируем. Основной фон — светлый, текст ≥ 7:1 на крупном и ≥ 4.5:1 на мелком, акценты насыщенные, без полупрозрачных светлых слоёв друг на друге (на проекторе «вымываются»). Токены `prefers-contrast`/`reduced-*` остаются. |
| Конфессиональная рамка | **Нейтральная духовная стилистика.** | Без креста, рыбы, голубя, витража, свитков и «библейской» гарнитуры. Смысл несут тексты игр, форма — современная и спокойная. |
| Название каталога | **Circle** (вместо EdenGames; идея: играем кругом, командой). В аудите ниже «EdenGames» остаётся там, где описано текущее состояние продукта. | Обновить шапку, metadata, футер игры, `lang`-заголовки и логотип; проверить домен и соцсети. Переименование в коде — отдельная задача. |
| Объём каталога | **5–6 игр** за первые 6 месяцев. | Фильтры не нужны: одна страница-витрина, у карточки — метаданные (команды · время · возраст) и статус «Скоро». Поиск и категории — после 12+ игр. |

## 3. Выбранное направление: «Утренний свет»

**Решение заказчика (2026-11-03):** вариант «Утренний свет» (вкладка B первой версии прототипа). Варианты «Табло», «Сетка», «Станок» и вкладки A, C, D–F сняты; прототип [`prototype/index.html`](prototype/index.html) оставлен для справки. Рамки, токены и запреты — в [`DESIGN.md`](DESIGN.md).

Суть: спокойный воздушный интерфейс — бледно-голубой фон `#EAF2F4`, крупные непрозрачные белые карточки (радиус 22 px) с мягкой тенью, солнечный акцент `#F5A524` (текст на нём `#12303A`), бирюза `#0F766E` для выбранного состояния. Шрифт Manrope 500–800 (кириллица), цифры табулярные. Цвет игры — плитка с глифом.

**Что взято из слоп-аудита и добавлено к варианту** (первоначальный вариант B содержал приёмы шаблона):

| В прототипе B | Решение |
|---------------|---------|
| Мягкое размытое пятно в hero (`blur-3xl`) | **убрано** |
| `backdrop-filter` на шапке | допускается только на липкой шапке портала; в игре и диалогах нет |
| Лозунг в hero («Спокойный светлый интерфейс…») | заменить конкретным текстом: что это и как начать |
| `font-extrabold` везде, `rounded-[28px]`, `shadow-card` на всём | вес 500–800 по иерархии; радиусы только токены 14/22; тень только `shadow-card`/`shadow-press` |
| Три цвета сложности «светофором» | различать числом очков, формой и подписью |
| Контрол 14 px/мелкие подписи | не меньше 14 px; база 18 px |

**Риск варианта:** ближе всего к «ещё одному современному веб-приложению». Сдерживается типографикой, цветом игр (плитка с глифом) и дисциплиной запретов из `DESIGN.md`.

**Фазы:** токены, примитивы, каталог — R03; игровое поле, настройки, админка, производительность — R04 (раздел 6).


## 4. Применение skill apple-design (что переносим)

- **Отклик на pointer-down:** карточка и кнопки реагируют на `:active`/`pointerdown` (`scale(0.97)`, 100 мс), а не только на hover. Hover-«приподнимания» на touch нет.
- **Пружины вместо длительностей:** флип карточки — spring с `damping 1.0`, response ≈0.3–0.4 с (без отскока: жеста с импульсом нет); отскок только для «матча/победы» после действия.
- **Прерываемость:** флип и TurnTransition не блокируют ввод; анимация стартует от текущего значения (Framer Motion это умеет — убрать CSS `transition-all` на том же элементе, `Card.tsx:22`).
- **Пространственная согласованность:** модалка уровня/вопроса выходит из карточки, которую открыли (`transform-origin` = плитка), и возвращается туда же. Правила/библиотека — единый паттерн «страница справа»: вход справа, выход вправо.
- **Типографика:** трекинг по размеру (крупное — `-0.02em`, мелкое — `+0.01…0.04em`, не `widest`); leading 1.05 / 1.5; размеры в `rem`, не px.
- **Материалы:** `backdrop-filter` только на липкой шапке портала; скорборд и диалоги в игре — непрозрачные, светлое полупрозрачное на светлом не стекаем.
- **Reduced motion/transparency/contrast:** три медиа-запроса в токенах; при reduce — кросс-фейд вместо флипа, без blur на паузе.
- **Обратная связь четырёх видов:** статус (чей ход), успех (пара), предупреждение (таймер < 5 с), ошибка (неверный ответ) — у каждого свой цвет **и** форма/иконка (не только цвет).
- **Agency:** вместо `confirm()` — отменяемое действие: «Вернуться на главную» → Undo-toast на 6 с или AlertDialog (только для необратимого сброса).

## 5. shadcn/ui на Base UI: карта замены

Инициализация: `npx shadcn@latest init` с выбором библиотеки примитивов **Base UI** (проверить актуальный флаг в CLI). В репозитории пока нет `components.json` и `components/ui` — это чистый старт; `lucide-react` уже в зависимостях.

| Сейчас | Atom | Примечание |
|--------|------|-----------|
| 7 кнопок в сайдбаре, START | `Button` (variant: primary / secondary / ghost / outline; size: lg для проектора) | заменить `bg-blue-600 …` на токены |
| Режим игры, число команд | `ToggleGroup` (single) | клавиатурная навигация из коробки |
| `LocaleSelector` | `Select` | сейчас кастомный dropdown |
| Поля имён команд, email/пароль | `Field` + `Input` + `Label` | inline-валидация, видимый focus-ring |
| `LevelSelectModal`, `QuestionModal`, `Victory` | `Dialog` | focus-trap, Esc, возврат фокуса |
| `window.confirm/alert` | `AlertDialog` + `Sonner` (toast) | 15 мест |
| `StepperInput` | `NumberField` (Base UI) | сейчас самописный |
| Прогресс | `Progress` | без `animate-pulse` |
| Таблица наборов (admin) | `Table` + `Badge` + `DropdownMenu` | |
| Навигация админки | `Sidebar` | вынести из layout `/admin/login` (группа маршрутов `(auth)`/`(panel)`) |
| Библиотека/правила | `Sheet` или отдельные страницы | единый паттерн |
| Иконки | `lucide-react` | заменить эмодзи; подпись — `aria-label` |

Игровые компоненты (`Card`, `Timer`, `ScoreBoard`) остаются самописными — это не atoms, а предметная часть; они берут токены (`--game-accent`, `--card-face`).
