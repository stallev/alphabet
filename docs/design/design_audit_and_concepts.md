# Аудит дизайна EdenGames и концепции редизайна

Дата: 2026-10-24. Источники: код репозитория (ветка R03) и живой деплой `alphabet-bible-quiz.vercel.app` (десктоп 1568 px; страницы `/`, `/alphabet`, `/alphabet#rules`, игровое поле после «Start game», `/admin/login`). Мобильный viewport через расширение не удалось эмулировать — мобильные выводы сделаны по коду и помечены «(код)».

## 1. Контекст, от которого надо отталкиваться

- Это **каталог** христианских игр для подростков и молодёжи, а не одна игра. Сейчас каталог (`/`) — заглушка из одной карточки, а весь «бренд» живёт внутри игры «Алфавит».
- Играют **командой у общего экрана** (проектор, ТВ, ноутбук на круге) и по одному на телефоне. Значит: читаемость с 3–5 метров, крупные цели, быстрый вход в игру, пауза/возврат без потери прогресса.
- Аудитория 13–25 лет: чувствует «как у взрослых по приколу» и «церковный плакат» одинаково фальшиво. Нужна собственная интонация, а не стоковая «Bible app».

### Принятые решения (заказчик, 2026-10-24)

| Вопрос | Решение | Следствие для дизайна |
|--------|---------|-----------------------|

Основной фон — светлый, текст ≥ 7:1 на крупном и ≥ 4.5:1 на мелком, акценты насыщенные, без полупрозрачных светлых слоёв друг на друге (на проекторе «вымываются»). ## 3. Три концепции

Общее для всех: **один бренд-слой на каталог** (EdenGames), а у каждой игры — **собственный цветовой «мир»** на 1–2 токена. Токены — CSS-переменные Tailwind 4 `@theme`, компоненты — shadcn/ui на Base UI.

Все три концепции **светлые** и без переключателя тем (см. «Принятые решения»). Интерактивный прототип со всеми тремя: [`prototype/index.html`](prototype/index.html) (один файл, Tailwind v4, семантические CSS-переменные; вкладки сверху переключают концепции, карточки на поле переворачиваются кликом).

### A. «Афиша» — типографический плакат (рекомендую)

Каталог как стена афиш: крупные буквы, плоские цветные блоки, плотная сетка, ничего «стеклянного». Для «Алфавита» это естественно — буква и есть изображение.

- **Палитра:** тёплая бумага `#F4EFE6`, чернила `#16130F`, 5 насыщенных плоских цветов на игры (кобальт `#2B4BFF`, терракота `#C8441A`, шафран `#F2B21B`, зелень `#1F7A52`, слива `#6A2C8F`). Один цвет на игру, без градиентов.
- **Шрифты:** заголовки — Unbounded или Onest 800 (проверить кириллицу), текст — Golos Text / Onest 400–500. Заголовки: `letter-spacing -0.02em`, `line-height 1.05`; текст 16–18 px, `line-height 1.5`; капс только для 12–13 px меток с `+0.04em`.
- **Каталог:** карточка игры = афиша 3:4 с огромным символом игры, названием, «2–5 команд · 30–45 мин · 13+». Hover/press — сдвиг на 2 px и «подпись» (offset-тень 4 px без размытия).
- **Игра:** карточки лицом вверх — цвет игры с чёрной буквой 56–96 px (контраст ≥ 7:1); рубашка — светлая бумага с нумерацией, как билет.
- **Плюсы:** узнаваемо, дёшево отрисовывать, отлично читается на проекторе, не похоже на «церковный сайт» и на «SaaS». **Минусы:** требует дисциплины в сетке; нужен свой набор иллюстраций-символов (можно простые геометрические).

### B. «Утренний свет» — мягкая светлая тема

(Заменяет прежний вариант «Вечерний костёр»: тёмная тема не нужна.) Спокойный воздушный интерфейс: бледно-голубой фон, белые крупные карточки с мягкой тенью, тёплый солнечный акцент.

- **Палитра:** фон `#EAF2F4`, карточки `#FFFFFF`, чернила `#12303A`, солнце `#F5A524` (текст на нём `#12303A`), бирюза `#0F766E`. Цвет игры — плитка с глифом.
- **Шрифт:** Manrope 500–800 (Cyrillic), цифры табулярные; заголовки `-0.02…-0.03em`.
- **Материалы** (правила Apple для веба): прозрачный `backdrop-filter` только на липкой шапке; единственное «свечение» — одно мягкое пятно в hero, статичное; светлое на светлом не стекаем (карточки непрозрачные).
- **Игра:** карточки — белые с тенью; открытая буква — на солнечном акценте с тёмным текстом.
- **Плюсы:** самая «спокойная» и универсальная, хорошо читается на проекторе, легче всего ложится на shadcn-токены. **Минусы:** меньше собственного характера, ближе всего к «ещё одному современному веб-приложению»; нужны сильные детали (типографика, цвет игр), чтобы не стать безликой.

### C. «Тетрадь и маркер» — записная книжка подростка

Страницы в клетку, маркер, стикеры, штампы. Тёплая, домашняя, «по-свойски».

- **Палитра:** лист `#FBF8F1` + линия `#D9D2C0`, маркерные жёлтый `#FFE24D`, розовый `#FF8FA3`, мятный `#8FE3C2`, синяя ручка `#24389C`.
- **Шрифты:** основной — Golos Text, акцентный рукописный — Caveat (Cyrillic) только для заголовков и крупных цифр, не для мелкого текста.
- **Элементы:** стикеры-теги, подчёркивание маркером на активном пункте, «скотч» на карточках игр.
- **Плюсы:** тёплая интонация, понятен подросткам, легко делать «ручные» иллюстрации. **Минусы:** самая высокая цена «кринжа» — легко превратить в школьный стиль для 10-летних; рукописные шрифты хуже читаются в мелком размере и на проекторе; много кастомной графики.

### Рекомендация

**A «Афиша»** как основа: максимальный контраст на проекторе при ярком свете, сильный характер, нейтральна по смыслу (никакой сакральной атрибутики). Из B можно взять мягкость контролов и тени, из C — рукописные акценты для экрана «Материалы ведущего». Окончательный выбор — за вами по прототипу.

## 4. Применение skill apple-design (что переносим)

- **Отклик на pointer-down:** карточка и кнопки реагируют на `:active`/`pointerdown` (`scale(0.97)`, 100 мс), а не только на hover. Hover-«приподнимания» на touch нет.
- **Пружины вместо длительностей:** флип карточки — spring с `damping 1.0`, response ≈0.3–0.4 с (без отскока: жеста с импульсом нет); отскок только для «матча/победы» после действия.
- **Прерываемость:** флип и TurnTransition не блокируют ввод; анимация стартует от текущего значения (Framer Motion это умеет — убрать CSS `transition-all` на том же элементе, `Card.tsx:22`).
- **Пространственная согласованность:** модалка уровня/вопроса выходит из карточки, которую открыли (`transform-origin` = плитка), и возвращается туда же. Правила/библиотека — единый паттерн «страница справа»: вход справа, выход вправо.
- **Типографика:** трекинг по размеру (крупное — `-0.02em`, мелкое — `+0.01…0.04em`, не `widest`); leading 1.05 / 1.5; размеры в `rem`, не px.
- **Материалы:** шапка игры/скорборд — полупрозрачный слой над полем, без 1 px-разделителя; не ставить светлое полупрозрачное на светлое.
- **Reduced motion/transparency/contrast:** три медиа-запроса в токенах; при reduce — кросс-фейд вместо флипа, без blur на паузе.
- **Обратная связь четырёх видов:** статус (чей ход), успех (пара), предупреждение (таймер < 5 с), ошибка (неверный ответ) — у каждого свой цвет **и** форма/иконка (не только цвет).
- **Agency:** вместо `confirm()` — отменяемое действие: «Вернуться на главную» → Undo-toast на 6 с или AlertDialog (только для необратимого сброса).

## 5. shadcn/ui на Base UI: карта замены

Инициализация: `npx shadcn@latest init` с выбором библиотеки примитивов **Base UI** (проверить актуальный флаг в CLI). В репозитории пока нет `components.json` и `components/ui` — это чистый старт; `lucide-react` уже в зависимостях.

| Сейчас | Atom | Примечание |
|--------|------|-----------|
| 7 кнопок в сайдбаре, START | `Button` (variant: primary / secondary / ghost / outline; size: lg для проектора) | заменить `bg-blue-600 …` на токены |
| Режим игры, число команд | `ToggleGroup` (single) | клавиатурная навигация из коробки |
| `LocaleSelector` | `Select` | сейчас кастомный dropdown |
| Поля имён команд, email/пароль | `Field` + `Input` + `Label` | inline-валидация, видимый focus-ring |
| `LevelSelectModal`, `QuestionModal`, `Victory` | `Dialog` | focus-trap, Esc, возврат фокуса |
| `window.confirm/alert` | `AlertDialog` + `Sonner` (toast) | 15 мест |
| `StepperInput` | `NumberField` (Base UI) | сейчас самописный |
| Прогресс | `Progress` | без `animate-pulse` |
| Таблица наборов (admin) | `Table` + `Badge` + `DropdownMenu` | |
| Навигация админки | `Sidebar` | вынести из layout `/admin/login` (группа маршрутов `(auth)`/`(panel)`) |
| Библиотека/правила | `Sheet` или отдельные страницы | единый паттерн |
| Иконки | `lucide-react` | заменить эмодзи; подпись — `aria-label` |

Игровые компоненты (`Card`, `Timer`, `ScoreBoard`) остаются самописными — это не atoms, а предметная часть; они берут токены (`--game-accent`, `--card-face`).

## 6. План (предлагаемые фазы после R03)

1. **Токены и основа** (`globals.css`: семантические переменные + `@theme inline`, только светлая тема, reduced-*; шрифты; `lang` по локали; shadcn init + 8 атомов).

3. **Настройки игры:** убрать сайдбар, один основной сценарий «Старт», остальное — «Материалы ведущего».
4. **Игровое поле:** новые карточки (контраст ≥ 7:1), spring-флип, таймер, пауза без blur, Dialog вместо модалок.
5. **Админка:** отдельный layout для login, Sidebar, Table; исправить `/game` → `/alphabet`.
6. **Производительность:** профилирование `initializeGame` и `RulesPage` (INP > 800 мс).
7. **Приёмка:** axe/контраст, проверка на проекторе (3 м), телефон 360 px, reduced-motion.
