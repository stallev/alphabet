## Цель

Довести интерфейс Alphabet и админки до направления «Утренний свет»: настройка игры без сайдбара с семью равнозначными кнопками, читаемое с проектора игровое поле, админка без «терминального» вида, без блокирующих `alert/confirm` и с приемлемым INP.

## Scope

1. **Настройки игры:** один основной сценарий «Начать игру»; библиотека вопросов, правила, импорт и AI-генератор — в «Материалы ведущего»; `ToggleGroup` для режима и числа команд.
2. **Игровое поле:** карточки с контрастом ≥ 7:1, spring-флип без отскока (Framer Motion, прерываемый), пауза без `blur`, таймер и смена хода по `DESIGN.md`, `Dialog` из kit вместо самописных модалок; сетка 13×4 (52 карточки), 7 и 4 колонки на узком экране, высота через CSS вместо JS `isDesktop`; карточка — `button` (роль, фокус, `Enter`/`Space`).
3. **Нативные `alert/confirm`** (15 мест в 9 файлах) → `AlertDialog` и toast (Undo-toast на 6 с для возврата на главную).
4. **Админка:** отдельный layout для `/admin/login` (без сайдбара), группы маршрутов `(auth)`/`(panel)`, `Sidebar`, `Table`, `Badge`, `DropdownMenu`; исправить ссылку «← Игра» (`/game` → `/alphabet`); вид — токены «Утреннего света», без `font-mono` и красного «терминала».
5. **shadcn/ui на Base UI** ([аудит §5](../../design/design_audit_and_concepts.md)) — для админки и сложных атомов (`Select`, `NumberField`, `Sheet`, `Table`); токены shadcn маппятся на токены R03. Решение о замене собственных `shared/ui` примитивов R03 на shadcn — по результатам Phase DoR audit (по умолчанию примитивы R03 остаются, shadcn — только то, чего в них нет).
6. **Производительность:** профилирование и устранение блокировок `initializeGame` (~813 мс) и `RulesPage` (~923 мс); цель INP < 200 мс на среднем телефоне.
7. **Остальные экраны Alphabet из baseline `tokens:check`** (редакторы, библиотека, AI-генератор, гид оператора, страница промпта) — на токены; baseline обнуляется.
8. **Приёмка:** axe/контраст, проверка на проекторе (3 м), телефон 360 px, `prefers-reduced-motion`.

## Out of scope

- Тёмная тема, фильтры и поиск в каталоге.
- Новые игры.
- Открытие индексации, hreflang, sitemap.
- Переименование домена и соцсетей Circle (вне репозитория).
- Локали `uk`, `de`, `ro`.

| Риск | Смягчение |
