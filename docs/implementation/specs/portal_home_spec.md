## §1 Структура страницы `/`

| Блок | Содержание |
|------|-----------|
| Шапка (`SiteHeader`) | Логотип/имя `SITE.name` (ссылка на `/`), `LocaleSwitcher`. Прилипает к верху (`sticky`), высота 56 px |
| Hero | `h1` — слоган портала; подзаголовок в одну-две строки. Без больших картинок (производительность) |
| Каталог | Сетка `GameCard` (§2) из `listGames()` |
| Подвал (`SiteFooter`) | © год, имя портала. Ссылки «О проекте»/«Конфиденциальность» — только когда страницы появятся |

Админская ссылка в шапке не показывается публично.

## §2 `GameCard`

Файл: `app/_components/GameCard.tsx` (специфичен для портала, не для игры).

| Элемент | Правило |
|---------|---------|
| Обложка | `next/image`, соотношение 16:9, `alt` = название игры; `sizes` под сетку; заглушка-градиент из токенов при отсутствии |
| Название | `manifest.title[locale]`, `h2`, максимум 2 строки |
| Слоган | `manifest.tagline[locale]`, максимум 2 строки |
| Теги | До 3 `Badge` с переводом тега из `catalog.tags.*` |
| Мета | Команды `{min}–{max}`, длительность (если есть), возраст «{minAge}+» (если есть) — компактной строкой с иконками `lucide-react` |
| Действие | `active`: кнопка «Играть» — вся карточка кликабельна (`<Link href="/{slug}">`, один фокусируемый элемент). `coming-soon`: бейдж «Скоро», карточка не ссылка (`aria-disabled`), приглушена |
| Состояния | default, hover (подъём тени), focus-visible (кольцо `focus`), `coming-soon` |

## §3 Адаптивность

| Ширина | Колонки | Отступы |
|--------|:------:|--------|
| 360 px | 1 | 16 px |
| 768 px | 2 | 24 px |
| 1280 px | 3 | 32 px, контейнер максимум 1120 px |

Без горизонтальной прокрутки; цели касания ≥ 44 px.

## §4 Пустые и крайние случаи

| Случай | Поведение |
|--------|-----------|
| В реестре нет игр | Сообщение `catalog.empty` и подсказка; без ошибок |
| Одна игра | Сетка не растягивает карточку на всю ширину (макс. ширина колонки) |
| Длинное название/слоган | Усечение по строкам (`line-clamp`) |
| Нет обложки у `coming-soon` | Градиентная заглушка |
| Много игр (≥ 12) | Сетка без пагинации; фильтры — вне объёма |

## §5 Метаданные и SEO

- `generateMetadata`: `title` = `SITE.name`, `description` = `site.description` из словаря; `robots` из `SITE.indexable`.
- Один `h1` на странице; порядок заголовков не пропускает уровни.

## §6 Тексты (ключи словаря `shared/i18n`)

`site.name`, `site.tagline`, `site.description`, `catalog.title`, `catalog.play`, `catalog.comingSoon`, `catalog.empty`, `catalog.teams` (plural), `catalog.minutes`, `catalog.age`, `catalog.tags.{memory|quiz|team|party|solo|kids|youth}`, `nav.home`.

## §7 Критерии приёмки

- [ ] Карточка Alphabet ведёт на `/alphabet`
- [ ] Временная запись `coming-soon` (локально, не коммитится) отображается как «Скоро» и не кликабельна
- [ ] Пустой реестр показывает `catalog.empty`
- [ ] Ширины 360/768/1280: колонки по §3, нет горизонтальной прокрутки
- [ ] Навигация клавиатурой: Tab проходит по карточкам и переключателю языка, фокус виден
- [ ] RU/EN переключаются без перезагрузки URL
