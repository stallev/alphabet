## §1 Раскладка

```
┌──────────────────────────────────────────────┐
│ ← Каталог   Название игры   [Правила] [RU|EN] [⋯] │  GameHeader (sticky, 56 px)
├──────────────────────────────────────────────┤
│                                              │
│            children (область игры)           │  <main>, контейнер ≤ 1280 px
│                                              │
└──────────────────────────────────────────────┘
```

| Зона | Содержимое |
|------|-----------|
| «← Каталог» | Ссылка на `/`. Во время `playing`/`paused` — открывает диалог подтверждения выхода (§3) |
| Название | `manifest.title[locale]` |
| «Правила» | Открывает `RulesDialog`, если передан `rules`; кнопка не отображается без `rules`. Во время `playing` открытие правил ставит игру на паузу через `onRulesOpenChange?` |
| `LocaleSwitcher` | RU \| EN |
| «⋯» | Меню: «Начать заново» (если передан `onRestart`) — с подтверждением, плюс `headerActions` игры |
| `<main>` | `children`; на мобильных — без внутренних горизонтальных отступов больше 16 px |

На ширине 360 px название усекается (одна строка), «Правила» и «⋯» остаются иконками с `aria-label`.

## §2 Фазы (`GamePhase`)

| Фаза | Значение для оболочки |
|------|----------------------|
| `lobby` | Экран настроек. Выход из игры без подтверждения. «Начать заново» скрыто |
| `playing` | Идёт игра. Выход и «Начать заново» — через подтверждение |
| `paused` | Как `playing`; поверх `children` — затемнение с подписью «Пауза» (если игра её не рисует сама — `pausedOverlay` prop) |
| `finished` | Как `lobby` для выхода без подтверждения; «Начать заново» доступно |

Оболочка **не хранит** состояние игры: фазу передаёт игра, действия возвращаются через callbacks.

## §3 Подтверждение выхода

Диалог `Dialog` (`shared/ui`): заголовок `gameKit.confirmExit.title`, текст `gameKit.confirmExit.body` (прогресс будет потерян), кнопки «Остаться» (по умолчанию в фокусе) и «Выйти» (`danger`). `Esc` = «Остаться». При закрытии вкладки (`beforeunload`) в фазах `playing`/`paused` браузерное предупреждение включено.

## §4 Ошибки

`GameShell` оборачивает `children` в error boundary: при падении игры показывается блок с сообщением `gameKit.error.title`, кнопка «Повторить» (сброс boundary) и ссылка «В каталог». Шапка остаётся рабочей.

## §5 Доступность

- Шапка — `<header>` с `nav`; `main` с `id="game-main"`; ссылка «Пропустить к игре» первой в DOM, видна при фокусе.
- Диалоги — focus trap, возврат фокуса на кнопку-источник.
- Смена фазы объявляется в `aria-live="polite"` (скрытая область): «Пауза», «Игра окончена».
- Порядок фокуса: пропуск → каталог → правила → язык → меню → содержимое.

## §6 Критерии приёмки

- [ ] Alphabet целиком отображается внутри `GameShell`; собственной шапки у игры нет
- [ ] Выход из `playing` показывает подтверждение; из `lobby` — нет
- [ ] Падение дочернего компонента (имитация `throw`) не ломает шапку
- [ ] На 360/768/1280 нет горизонтальной прокрутки, цели касания ≥ 44 px
- [ ] Все тексты — из `gameKit.*` или из словаря игры; RU/EN работают
