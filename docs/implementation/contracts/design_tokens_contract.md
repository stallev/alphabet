## §1 Принцип

Единый внешний вид игр обеспечивается **семантическими токенами** в Tailwind v4 `@theme`. Код игр и kit использует только утилиты, порождённые токенами (`bg-surface`, `text-fg-muted`, `rounded-card`), и не использует палитровые утилиты (`bg-blue-500`), произвольные значения (`bg-[#1e3a8a]`, `text-[13px]`) и hex/rgb в стилях.

В `@theme` стандартные `--radius-*`, `--shadow-*`, `--blur-*` обнуляются (остаются только токены §2.3), поэтому утилиты `rounded-lg`, `shadow-md` и подобные не существуют.

Файл токенов: `shared/styles/tokens.css`, подключается в `app/globals.css` через `@import`.

## §2 Токены (направление «Утренний свет»; значения — из [`DESIGN.md`](../../design/DESIGN.md), финал `success`/`danger`/`team-*` — в R03-T1 с одобрением владельца)

Источник значений — выбранное направление дизайна (решение заказчика 2026-11-03), а не палитра `COLORS` из `constants.ts`.

|-------|---------|------------------|-----------|
| `--color-bg` | `bg-bg` | `#eaf2f4` | Фон страницы |

| `--color-surface-muted` | `bg-surface-muted` | `#eef4f5` | Вторичные области, подложка сегмент-контролов |
| `--color-border` | `border-border` | `#c9d8dc` | Границы |
| `--color-fg` | `text-fg` | `#12303a` | Основной текст |
| `--color-fg-muted` | `text-fg-muted` | `#4a6068` | Вторичный текст (контраст на `bg` ≥ 4.5:1) |
| `--color-primary` | `bg-primary` | `#0f766e` | Выбранное состояние, ссылки, вторичные основные кнопки |
| `--color-primary-fg` | `text-primary-fg` | `#ffffff` | Текст на primary |
| `--color-accent` | `bg-accent` | `#f5a524` | Главное действие, текущий ход, открытая буква |

| `--color-danger` | `bg-danger` | подбирается (≥ 4.5:1 с белым) | Неверно, опасные действия, таймер < 5 с |
| `--color-focus` | `ring-focus` | = `primary` | Кольцо фокуса: 3 px, отступ 2 px |

Для каждого фонового токена существует парный `*-fg`, если на нём размещается текст. «Светофор» зелёный/янтарный/красный для сложности не используется: уровни различаются числом очков и подписью. Индиго/фиолетовый как основной цвет запрещён; `game-5`/`team-5` — второстепенные цвета.

### §2.2 Типографика

| Токен | Значение |
|-------|----------|
| `--font-sans` | `Manrope` 500–800 (subsets `latin`, `cyrillic`) через `next/font`; заменяет `Inter` из `app/layout.tsx` |
| Базовый кегль | 18 px (`line-height` 1.5), размеры в `rem`; минимум 14 px (`text-sm`) |
| `--text-xs…3xl` | Шкала Tailwind по умолчанию; `text-xs` не используется в игровых экранах; других размеров не использовать |
| Начертания | 500 (текст), 600–700 (подписи, кнопки), 800 (заголовки, акцентные числа); `font-black`, `uppercase`, `italic`, `tracking-widest` не используются |
| Цифры | `tabular-nums` для очков и таймера |

### §2.3 Форма, отступы, тени

| Токен | Значение |
|-------|----------|
| `--radius-ctl` | 10 px (кнопки, поля, сегменты) |
| `--radius-ctl-sm` | 8 px (теги, badge, мелкие сегменты) |
| `--radius-card` | 18 px (карточки, диалоги, поле) |
| `--radius-full` | круглые элементы (счёт, таймер) |
| Отступы | Шкала Tailwind (4 px × n); произвольные значения запрещены |
| `--shadow-card` | `0 1px 2px rgb(18 48 58 / .06), 0 6px 16px -8px rgb(18 48 58 / .12)` |
| `--shadow-press` | `inset 0 1px 2px rgb(18 48 58 / .08)` (только `:active`) |
| `--z-modal`, `--z-toast` | 50, 60 |
| Высоты контролов | 44 px (`h-11`, обычный) и 56 px (`h-14`, главное действие); рядом стоящие — одной высоты |
| Мин. цель касания | 44 px (WCAG); контролы ≥ 44 px |

Других радиусов и теней, а также размытий/градиентов/`backdrop-filter` (кроме липкой шапки портала) в системе нет — см. запреты в [`DESIGN.md`](../../design/DESIGN.md).

### §2.4 Темы

Токены определены в `:root` для светлой темы. Только светлая палитра, без переключателя; тёмная тема не проектируется. Медиа-запросы `prefers-reduced-motion` (кросс-фейд вместо флипа, без анимации диалогов) и `prefers-contrast` учитываются в `tokens.css`.

## §3 Проверка

Скрипт `scripts/check-design-tokens.mjs` (`npm run tokens:check`) сканирует `games/**` и `shared/game-kit/**` (`*.tsx`, `*.css`) и падает на:

| Паттерн | Причина |
|---------|--------|
| `#[0-9a-fA-F]{3,8}` вне строк в `data/` и `i18n/` | сырой цвет |
| `\b(rgb|rgba|hsl|hsla)\(` | сырой цвет |
| `\b(bg|text|border|ring|from|to|via|fill|stroke)-(red|orange|amber|yellow|lime|green|emerald|teal|cyan|sky|blue|indigo|violet|purple|fuchsia|pink|rose|slate|gray|zinc|neutral|stone)-\d{2,3}\b` | палитровая утилита |
| `\[(\d+px|#[0-9a-fA-F]+)\]` внутри `className` | произвольное значение |
| `\b(uppercase|italic|font-black|tracking-(wider|widest))\b` | приём оформления из запретов `DESIGN.md` |
| `\b(bg-(gradient|linear|radial)[\w-]*|blur-\w+|backdrop-blur[\w-]*|drop-shadow[\w-]*)\b` | градиенты, размытия (`backdrop-blur` разрешён только в `app/_components/SiteHeader.tsx` через `/* tokens:allow */`) |
| `\b(rounded|shadow)-(sm|md|lg|xl|2xl|3xl)\b` | радиусы и тени только токены §2.3 (в `@theme` стандартные значения обнулены, утилит нет) |
| эмодзи (`\p{Extended_Pictographic}`) в `*.tsx` | иконки — `lucide-react` |

`shared/ui` (примитивы) проверяется теми же правилами, кроме файла `tokens.css`. Исключения — строка-комментарий `/* tokens:allow <причина> */` на предыдущей строке; их количество фиксируется в отчёте CU.

### §3.1 Baseline для унаследованного кода (ratchet)

В Alphabet на момент R02 ≈ 630 палитровых утилит и ≈ 80 произвольных значений. Переписывать весь UI игры ради R03 не требуется. Поэтому:

- `scripts/tokens-baseline.json` хранит `{ "<файл>": <число нарушений> }` для **унаследованных** файлов Alphabet, не переведённых на токены в R03 (редакторы и библиотека вопросов, AI-генератор, оператор-гайд, страница промпта);
- для файла из baseline допустимо **не больше** записанного числа нарушений (число можно только уменьшать; рост — ошибка);
- любой файл вне baseline — нулевая терпимость; новые файлы в baseline не добавляются;
- файлы игрового экрана Alphabet (карточки, лобби, вопросы, победа) переводятся на токены в R03 и в baseline не входят.
