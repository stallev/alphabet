## §1 Принцип

Единый внешний вид игр обеспечивается **семантическими токенами** в Tailwind v4 `@theme`. Код игр и kit использует только утилиты, порождённые токенами (`bg-surface`, `text-fg-muted`, `rounded-lg`), и не использует палитровые утилиты (`bg-blue-500`), произвольные значения (`bg-[#1e3a8a]`, `text-[13px]`) и hex/rgb в стилях.

Файл токенов: `shared/styles/tokens.css`, подключается в `app/globals.css` через `@import`.

## §2 Токены (начальные значения; тонкая настройка — в R03-CU1 с одобрения владельца)

Начальные значения взяты из текущей палитры Alphabet (`COLORS` в `constants.ts`).

### §2.1 Цвет

| Токен | Утилита | Значение (light) | Назначение |
|-------|---------|------------------|-----------|
| `--color-bg` | `bg-bg` | `#f8fafc` | Фон страницы |
| `--color-surface` | `bg-surface` | `#ffffff` | Карточки, диалоги |
| `--color-surface-muted` | `bg-surface-muted` | `#f1f5f9` | Вторичные области |
| `--color-border` | `border-border` | `#e2e8f0` | Границы |
| `--color-fg` | `text-fg` | `#0f172a` | Основной текст |
| `--color-fg-muted` | `text-fg-muted` | `#475569` | Вторичный текст (контраст на `bg` ≥ 4.5:1) |
| `--color-primary` | `bg-primary` | `#1e3a8a` | Основной акцент, кнопки |
| `--color-primary-fg` | `text-primary-fg` | `#ffffff` | Текст на primary |
| `--color-accent` | `bg-accent` | `#fbbf24` | Выделение, очки, «победа» |
| `--color-accent-fg` | `text-accent-fg` | `#1f2937` | Текст на accent |
| `--color-success` | `bg-success` | `#10b981` | Верно |
| `--color-danger` | `bg-danger` | `#ef4444` | Неверно, опасные действия |
| `--color-focus` | `ring-focus` | `#2563eb` | Кольцо фокуса |
| `--color-team-1…6` | `bg-team-1…6` | 6 различимых цветов, различимы при дальтонизме (не только красный/зелёный) | Команды |

Для каждого фонового токена существует парный `*-fg`, если на нём размещается текст.

### §2.2 Типографика

| Токен | Значение |
|-------|----------|
| `--font-sans` | `Inter` (subsets `latin`, `cyrillic`), как сейчас в `app/layout.tsx` |
| `--text-xs…3xl` | Шкала Tailwind по умолчанию; других размеров не использовать |
| Начертания | 400 (текст), 700 (заголовки), 900 (акцентные числа) |

### §2.3 Форма, отступы, тени

| Токен | Значение |
|-------|----------|
| `--radius-sm / md / lg / xl` | 6 / 10 / 16 / 24 px |
| Отступы | Шкала Tailwind (4 px × n); произвольные значения запрещены |
| `--shadow-card`, `--shadow-modal` | по одному значению каждая |
| `--z-modal`, `--z-toast` | 50, 60 |
| Мин. цель касания | 44 px (`min-h-11`) |

### §2.4 Темы

Токены определены в `:root` для светлой темы. Тёмная тема в объём не входит; структура (`:root` + `[data-theme="dark"]`) оставлена открытой.

## §3 Проверка

Скрипт `scripts/check-design-tokens.mjs` (`npm run tokens:check`) сканирует `games/**` и `shared/game-kit/**` (`*.tsx`, `*.css`) и падает на:

| Паттерн | Причина |
|---------|--------|
| `#[0-9a-fA-F]{3,8}` вне строк в `data/` и `i18n/` | сырой цвет |
| `\b(rgb|rgba|hsl|hsla)\(` | сырой цвет |
| `\b(bg|text|border|ring|from|to|via|fill|stroke)-(red|orange|amber|yellow|lime|green|emerald|teal|cyan|sky|blue|indigo|violet|purple|fuchsia|pink|rose|slate|gray|zinc|neutral|stone)-\d{2,3}\b` | палитровая утилита |
| `\[(\d+px|#[0-9a-fA-F]+)\]` внутри `className` | произвольное значение |

`shared/ui` (примитивы) проверяется теми же правилами, кроме файла `tokens.css`. Исключения — строка-комментарий `/* tokens:allow <причина> */` на предыдущей строке; их количество фиксируется в отчёте CU.

### §3.1 Baseline для унаследованного кода (ratchet)

В Alphabet на момент R02 ≈ 630 палитровых утилит и ≈ 80 произвольных значений. Переписывать весь UI игры ради R03 не требуется. Поэтому:

- `scripts/tokens-baseline.json` хранит `{ "<файл>": <число нарушений> }` для **унаследованных** файлов Alphabet, не переведённых на токены в R03 (редакторы и библиотека вопросов, AI-генератор, оператор-гайд, страница промпта);
- для файла из baseline допустимо **не больше** записанного числа нарушений (число можно только уменьшать; рост — ошибка);
- любой файл вне baseline — нулевая терпимость; новые файлы в baseline не добавляются;
- файлы игрового экрана Alphabet (карточки, лобби, вопросы, победа) переводятся на токены в R03 и в baseline не входят.

## §4 Критерии соответствия

- [ ] Токены из §2 определены в `shared/styles/tokens.css`
- [ ] `npm run tokens:check` зелёный; файлы игрового экрана Alphabet и весь `shared/**` — без нарушений; остальное — в baseline (§3.1)
- [ ] Контраст пар `*-fg` на своих фонах ≥ 4.5:1 (проверено вручную по таблице в отчёте R03-CU1)
